本模块为纯文档目录，按职责拆分为多份 Markdown 文件：`architecture.md` 定义整体技术栈（Spring Cloud Alibaba + Vue 3）、11 个微服务模块的职责与端口/数据库映射、包结构约定（传统分层 vs DDD）；`api-contract.md` 统一 `Result<T>` 响应包装与错误码分类、内部服务调用 Header 鉴权；`infrastructure.md` 描述 MySQL/Redis/Nacos/RabbitMQ 等中间件默认地址、Gateway 路由映射、RabbitMQ Topic Exchange 事件路由及 Docker Compose 编排；`testing.md` 规定后端 JUnit5+Mockito 单测、SpringBootTest+Testcontainers 集成测试、前端 Vitest 组件/Store/API 测试模式；`jasypt-key-management.md` 给出 AES/GCM/NoPadding 加密算法、ENC() 格式、Nacos 透明解密流程与密钥轮换步骤；其余 `claude-*.md` 为 AI 辅助开发的上下文提示。依赖方向单向：所有文档相互引用但不被代码反向依赖，作为跨模块的单一事实来源。
