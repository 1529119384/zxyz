- API 文件统一从 `@/utils/request` 导入并暴露命名函数，URL 路径以 `/api/admin/` 为前缀，参数通过对象或模板字符串传递。
- 弹窗组件采用受控模式：通过 `visible` prop 控制显示，使用 `update:visible` 事件同步状态，业务动作通过自定义事件（submit/select）向上抛出。
- 长耗时请求在调用处定义常量超时时间并通过 axios config 传入（如 DATABASE_MAINTENANCE_TIMEOUT、EMAIL_CONNECTIVITY_TIMEOUT）。
- 需要二进制响应的接口（如数据库导出）显式设置 `rawBlob: true` 和 `responseType: 'blob'`。
- 组件内样式使用 `<style scoped>`，CSS 类名采用 BEM 风格（如 `.conversation-option__content`）。
