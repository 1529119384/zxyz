模块按职责分为两层：
- API 层（src/api/）：configAdmin.js、databaseAdmin.js、emailAdmin.js、storage.js 四个文件分别对应配置管理、数据库维护、邮件服务、存储提供者四大管理域，统一通过 `@/utils/request` 发起 REST 请求，所有接口路径均以 `/api/admin/` 前缀开头，保持与后端 admin 网关的约定。
- 组件层（src/components/）：InputDialog.vue、ProjectSettingsDialog.vue、ConversationPickerDialog.vue 均为基于 Element Plus 的受控弹窗，使用 `<script setup>` + `defineProps`/`defineEmits` 暴露 `visible` 双向绑定和领域事件；uploader/shared.js 提供上传结果摘要格式化的纯函数工具。
依赖方向单向向下：组件不直接调用后端，API 文件也不依赖 UI 组件，仅通过 request 工具与网络层交互。
