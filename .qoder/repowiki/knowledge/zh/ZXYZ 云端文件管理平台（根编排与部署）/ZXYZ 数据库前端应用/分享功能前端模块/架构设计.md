本模块按职责拆分为三层：
- API 层（`src/api/share.js`）：封装所有分享相关 HTTP 请求，区分 `request`（需登录的 `/api/shares`）与 `publicRequest`（公开的 `/api/public/shares`），并通过 `@/models/share` 中的映射函数对响应数据进行标准化。
- Model 层（`src/models/share.js`）：集中定义分享状态枚举、过期选项、密码生成/校验/清洗、分享文案构建、分页数据映射等纯函数，被 API 与组件共同复用。
- Composables 层（`src/composables/use*.js`）：每个组合函数聚焦单一场景——`useShareCreateAction` 管理创建对话框与提交流程，`useMyShareList` 管理我的分享分页列表与取消操作，`useShareVisit` 处理公开分享页的权限校验与提取码验证，`useShareFileList` 加载公开分享文件列表，`useShareFileDownload` 获取单文件下载 URL 或走流式下载，`useShareArchiveDownload` 基于 `useArchiveDownload` 封装分享目录打包下载，`useShareFileNavigation` 通过路由 query 维护当前目录路径。
- Components 层（`src/components/*.vue`）：`CreateShareDialog` 负责分享表单输入与校验，`ShareSuccessDialog` 展示成功结果并支持复制文案，`ShareFileExplorer` 以表格+面包屑展示公开分享文件并提供下载/打包入口，`FileCardPickerDialog` 提供文件选择器供创建分享时挑选目标资源。
依赖方向严格单向：Components → Composables → API → Models，Composables 之间仅通过共享工具函数（如 `@/utils/*`）协作，无循环依赖。
