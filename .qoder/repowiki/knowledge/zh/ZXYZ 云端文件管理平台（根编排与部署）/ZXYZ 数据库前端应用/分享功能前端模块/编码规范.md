- 每个业务场景封装为一个独立的 `useXxx` composable，统一返回 `{ loading, data, error, actions }` 形式的响应式状态与方法集合。
- API 调用统一使用 try/catch 包裹，错误通过 `handleBusinessError` 或 `getErrorMessage` 统一处理，并在 finally 中重置 loading 状态。
- 对外暴露的数据通过 `mapXxx` / `mapXxxRecords` 等映射函数在 API 层转换为统一的展示模型，避免组件直接处理原始接口字段。
- 组件间通过 `defineProps` + `defineEmits` 进行通信，弹窗类组件统一使用 `update:visible` 双向绑定控制显隐。
- 公开分享相关请求一律使用 `publicRequest`，内部用户操作使用 `request`，在 `src/api/share.js` 中明确区分两类客户端。
- 密码相关逻辑集中在 `@/models/share.js` 中，通过 `generateSharePassword`、`sanitizeSharePassword`、`isValidSharePassword` 三件套保证输入一致性与安全性。
