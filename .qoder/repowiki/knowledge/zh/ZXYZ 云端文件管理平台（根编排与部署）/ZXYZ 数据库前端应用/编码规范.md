- 业务逻辑下沉至 composables（useXxx.js），组件仅负责渲染与事件派发
- API 调用集中在 src/api/* 模块，按功能域拆分文件，组件不直接调用 axios
- 全局状态统一存放在 Pinia store（currentUser、session、team、im/chat），通过 useStore 或 composables 访问
- HTTP 请求统一走 utils/request.js，错误处理与拦截器集中管理
- 单元测试与源码同目录 __tests__ 或 .spec.js 后缀，使用 Vitest + @vue/test-utils
- 提交信息遵循 conventional commits，由 Husky + Commitlint 强制校验
