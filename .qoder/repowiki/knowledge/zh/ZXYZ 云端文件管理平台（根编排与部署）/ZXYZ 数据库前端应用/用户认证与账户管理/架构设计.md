模块按职责划分为三层：
- API 层（`src/api/auth.js`、`account.js`、`user.js`）：基于 `@/utils/request` 封装所有后端 `/api/users/*` 接口，包括登录、注册、获取当前用户、登出、联系方式绑定与验证、头像上传签名、密码修改、设置读写等。
- Store 层（`src/store/currentUser.js`、`session.js`）：使用 Pinia 定义 `useCurrentUserStore` 和 `useSessionStore`，前者负责用户 profile 的本地持久化（仅缓存显示字段到 localStorage）、权限计算与登录/登出状态；后者通过 `ensureSessionReady` 协调 currentUser 与 team 两个 store 完成会话引导，并处理并发初始化竞态（pendingSessionReady + sessionVersion）。
- Composables 层（`src/composables/useLoginForm.js`、`usePasswordChange.js`、`useProfileForm.js`、`useContactVerification.js`、`usePostLoginGuide.js`）：每个 composable 聚焦单一业务场景，组合 store 调用与表单状态，统一通过 `handleBusinessError` 处理错误并通过 ElMessage 反馈。
- UI 组件（`LogoutDialog.vue`）：纯展示型弹窗，通过 v-model + emit 与父组件通信，实际登出逻辑由父组件委托 store 执行。
依赖方向严格自上而下：composables → store → api → utils/request，store 之间通过 Pinia 实例互相引用但不形成循环。
