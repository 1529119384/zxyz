- API 函数统一通过 `imRequest.get/post/patch/delete` 调用，URL 遵循 `/api/im/*` 或 `/api/team-collaboration/*` 路径前缀，参数通过 `{ params }` 传递。
- Store 内部按领域拆分 domain 模块（conversation/message/notification/realtime），通过闭包依赖对象注入跨域方法，避免直接 import 其他 store。
- 组合式函数接受 options 参数并允许传入 mock 的 store 实例（如 `teamStore = useTeamStore()` 默认值），便于测试与复用。
- 枚举常量同时导出单个字符串值和 `Object.freeze` 聚合对象（如 `CONVERSATION_TYPE`、`MESSAGE_STATUS`），供不同场景按需引用。
- WebSocket 信封统一包含 `type`、`requestId`、`clientMessageId`、`conversationId`、`payload`、`timestamp` 字段，通过 `createEnvelope` 工厂函数创建。
- 错误处理统一通过 `handleBusinessError` 包装业务异常，用户提示使用 Element Plus 的 `ElMessage` 组件。
