模块采用典型的 Vue 3 组合式架构，按职责划分为四层：
- 组件层（components）：FileExplorer.vue 作为主入口，聚合 FileUploader.vue、FolderUploader.vue、RecycleBinExplorer.vue 等子组件，并通过 defineExpose 暴露 refresh/openFolder/clearSelection 等方法供父组件调用。
- 组合函数层（composables）：每个 composable 封装单一业务能力，如 useSpaceFileList 负责列表加载分页、useFileUpload 管理上传对话框与进度、useSelectionManager 处理多选/Shift/Ctrl 选择、useFileNavigation 维护面包屑路径、useFileSearch 实现搜索模式切换等。
- 模型层（models）：file.js 负责后端数据到前端展示对象的映射（mapSpaceFileEntries/mapSearchFileEntries/mapRecycleFileEntries），filePresentation.js 提供 createDisplayFileEntry/getFileIcon/splitFileNameParts 等展示工具，fileActions.js 定义操作类型常量。
- API 层（api/files.js）：集中所有 HTTP 请求，统一通过 request 工具发起，并调用 models 中的映射函数将响应标准化。
依赖方向严格自上而下：组件 → composables → api/models → utils/services，composables 之间通过 props/options 解耦，避免循环依赖。
