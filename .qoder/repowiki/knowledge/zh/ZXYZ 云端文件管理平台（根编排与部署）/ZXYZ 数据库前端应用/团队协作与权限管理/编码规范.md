- 所有 API 函数统一通过 `@/utils/request` 发起 HTTP 请求，路径遵循 RESTful 风格并以 `/api/` 前缀区分业务域。
- Store 中的响应式数据一律通过 `readonly()` 包裹后再暴露，防止外部直接修改 state。
- 权限判断使用 `teamStore.hasTeamPermission({ teamId, code })` 配合 `TEAM_PERMISSION_CODES` 常量进行，避免硬编码权限字符串。
- 组件采用 `defineProps` + `defineEmits` 声明式接口，双向绑定统一使用 `update:*` 事件命名约定。
- 异步操作失败统一通过 `handleBusinessError(error, message)` 捕获并提示，成功反馈使用 `ElMessage.success/warning`。
- 空间相关参数通过 `normalizePositiveId` 和 `normalizeSpaceType` 进行安全归一化，保证 teamId/projectId/spaceType 始终有效。
