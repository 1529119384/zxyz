本模块按职责划分为四个子目录：
- `deploy/nginx/`：Nginx 反向代理配置，统一将 `/api/*`、`/im-api`、`/ws` 请求转发至 gateway:18000，并通过 `entrypoint.sh` 使用 `envsubst` 注入 OSS_PUBLIC_BASE_URL；同时启用 gzip、CSP、限流（auth_per_ip/api_per_ip）和安全头。
- `deploy/promtail-config.yml`：Promtail 采集 Docker 容器日志并推送到 Loki，通过 docker_sd_configs 自动发现容器标签 service/container/logstream。
- `nacos-config/`：每个微服务对应一个 `zxyz-*-service.yml` 配置文件，由 `import.sh` 批量通过 Nacos v1/cs/configs API 以 group=ZXYZ、tenant=namespace 方式幂等导入；Gateway 仅引入 zxyz-dynamic.yml，敏感值使用 ENC() 格式配合 jasypt 解密。
- `scripts/`：围绕 docker-compose 的完整生命周期管理——`dev-up.sh` 启动本地基础设施（MySQL/Nacos/Redis/RabbitMQ），`deploy-fast.sh` 支持增量构建/拉取/重启/健康检查，`rollback.sh` 基于 `.env.previous` 一键回滚，`backup.sh` 对 MySQL 和 Redis 做定时备份并可选异地同步，`health-check.sh` 汇总所有容器健康状态，`validate-env.sh` 校验 .env 必填项并自动补全缺失键，`setup-acr.sh` 在 ACR 与 GHCR 镜像源间切换。
- `sql/00-init-zxyz.sh`：MySQL 官方镜像首次启动时自动执行，创建各业务库（project/im/email/share/file/team/user/audit/config/nacos），表结构由各服务 Flyway 迁移负责。
依赖方向：脚本 → docker-compose → 容器服务；Nacos 配置 → import.sh → Nacos API；Nginx → Gateway → 各微服务。
